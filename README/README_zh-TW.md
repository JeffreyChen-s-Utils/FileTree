# FileTree

**看看磁碟空間都用到哪裡去了。** FileTree 會掃描一個資料夾或整顆磁碟，把裡面每個檔案的大小加總，先列出最大的資料夾和檔案——用資料夾樹、彩色的方塊圖和最大檔案清單呈現。找到不需要的東西時，直接在視窗裡把它移到資源回收筒。

[English](../README.md) | [繁體中文](README_zh-TW.md) | [简体中文](README_zh-CN.md)

![FileTree 顯示一個使用者資料夾：左邊是資料夾樹，右邊是方塊圖](../docs/images/main_window_zh-TW.png)

掃描列的「**暫停／繼續**」會暫停取得新資料夾。目前的資料夾讀取會完成，資料夾樹仍持續更新；暫停時仍可「停止」或關閉視窗。最後的結果分析不能暫停。經過時間包含暫停期間，繼續時保留同一份掃描及計數。

「**選項 → 低優先順序掃描**」預設關閉，套用到新掃描。每個掃描執行緒使用 Windows 背景 CPU／I/O 模式，或 Linux nice 10 與最低的 best-effort I/O 優先順序，不影響介面執行緒。不支援的平台、權限拒絕或僅部分套用會回報；可讀資料夾仍繼續掃描。I/O 效果取決於磁碟排程器，掃描可能花較久時間。命令列及量測工具接受 `--gentle`，命令列 JSON 包含 `warnings`。

矩形樹圖與放射圖共用「**顏色 → 依修改檔齡**」，使用「檔齡」清單的範圍，並顯示由淺（近期）到深（較舊）的圖例。顏色依掃描／分析時間計算，游標移動時不會隨時鐘改變。資料夾依最新的修改記錄著色；無可用日期、未來日期與合併的小項目為灰色。這表示修改檔齡，不能判斷最後存取時間或是否未使用。

「**檔案 → 匯出**」與圖表右鍵選單可將畫面上的圖表儲存為 **PNG**，包含目前可見範圍、配色及選取狀態。長條圖與放射圖另提供 **SVG**：有數量上限的完整長條列或圓弧會繪製成向量圖形與文字，不使用放射圖的快取點陣圖。PNG 編碼與檔案寫入由匯出工作執行緒處理，以原子方式替換檔案；關閉視窗會等待匯出完成。

「**檔案 → 列印目前畫面**」（`Ctrl+P`）會開啟系統列印對話框。「**檔案 → 匯出 → 目前畫面（PDF）**」會儲存一頁 A4，依擷取畫面選擇橫向／直向。兩者將目前分頁及可見範圍等結果等比例放入可列印邊界，不拉伸或裁切；輸出是擷取的像素，捲動範圍外的項目不在其中。PDF 由匯出工作執行緒使用 Qt PDF 引擎寫入，以原子方式替換指定檔案；關閉視窗會等待完成。

圖表分頁提供可點擊的資料夾路徑與 **返回／前進**（`Alt+Left`／`Alt+Right`）。歷程保留目前掃描最近 100 次導覽；返回後開啟其他資料夾會取代前進歷程。新掃描會重設歷程，重新掃描會移除失效項目。長路徑可水平捲動，**…** 可選擇更上層的資料夾。

展開資料夾樹下的 **詳細資訊**，可查看選取項目的大小、磁碟大小、檔案與資料夾數、已記錄的修改日期，以及小型類型與檔齡分布。面板會記住展開狀態；掃描結束且面板展開時才在可取消的背景工作中計算分布，僅使用已讀取項目，未知與未來日期分開列出。更換選取項目會捨棄過期結果，關閉視窗會等待工作結束。

**檔案 → 匯出 → 目前清單（CSV）** 可儲存搜尋、重複檔案、變更、檔案類型、檔案新舊、最大的檔案、清理建議或問題清單，保留顯示的標籤、單位、篩選與排序。分組清單包含群組標題及其項目，即使已收合亦然。清單或資料夾樹取得焦點時，**Ctrl+C** 會將選取列與欄名複製成含引號的定位字元分隔文字；文字欄位仍正常複製。看似公式的文字會加上試算表保護前綴。CSV 擷取會以短批次讓出介面，透過有上限的佇列交給背景工作原子寫入；清單變更會取消匯出並保留既有目的檔案。

在 **檔案類型** 連按兩下副檔名，即可同時查看最大的符合檔案與最多 1,000 個 **所在資料夾**，包含符合類型的大小、檔案數及占全部符合位元組的比例。資料夾僅計算直接包含的檔案，巢狀資料夾不會重複計算。兩份清單在可取消的背景工作中一起計算，並遵循 **僅選取的資料夾** 範圍。變更副檔名、掃描或範圍會捨棄舊結果；**顯示全部** 可回到一般清單。依檔齡查看檔案也在背景執行。

Windows 的 **詳細資訊** 會解釋休眠、分頁與交換檔、Windows.old、資源回收筒、System Volume Information、WinSxS、Windows Update 下載及傳遞最佳化快取。辨識使用磁碟根目錄或目前 Windows 安裝的完整位置，包含其子項目，不會僅憑同名判定。按鈕開啟對應的 Windows 設定或系統工具；FileTree 不執行清理命令，也不移動這些系統管理項目。操作背景工作亦會拒絕包含它們的資料夾，並重新檢查解析後的路徑。WinSxS 加總可能包含共用硬式連結；未讀取的系統資料仍未知。

四種圖表提供輔助工具名稱、鍵盤操作說明，以及目前資料夾與選取項目的已記錄大小及數量。以 Tab 或點擊將焦點移至圖表：**方向鍵** 選取已繪製項目，**Enter** 開啟選取的資料夾，**Backspace** 返回上層。樹狀圖保留上／下選取卡片及右／左展開、收合的操作；長條圖與樹狀圖會將選取列捲動至可見位置。導覽使用有上限的圖表版面，合併或未顯示的項目可在資料夾樹查看。Alt+Left 等組合快捷鍵保持原有操作。

**檢視 → 主題 → 系統／淺色／深色** 可立即切換並記住選擇。系統模式恢復原生平台樣式與色盤；指定主題使用一致的 Qt 控制項，以及清楚的文字、選取與停用顏色。色盤或樣式變更會重新繪製圖表。方塊圖與放射圖依實際填色對比選擇黑字或白字；方塊圖僅在漸層兩端都維持至少 4.5:1 對比時保留漸層。長條圖的名稱與數值使用目前色盤，顯示在彩色長條之外。

## 功能

- **按一下就開始**：選一個資料夾、按一下磁碟、把資料夾拖曳到視窗上，或貼上路徑。
- **平行、邊掃邊看**：同時讀取多個資料夾；兩個工作執行緒記錄檔案身分時，約 202 萬筆的 Windows 系統碟耗時 208 秒。掃描時資料夾樹就會陸續出現，最大的資料夾排在最前面；按停止會留下已經讀到的部分。
- **資料夾樹**：由大到小排列，每一列有它實際佔用的磁碟空間、顯示它佔所在資料夾比例的長條，還有檔案數、資料夾數與裡面最近一次變動的時間。
- **圖表**，四種看資料夾的方式，在分頁角落切換（一開始是方塊圖）：**方塊圖**（每個檔案一個方塊，大小代表佔用的空間；資料夾裡小到看不見的檔案合成一個斜線方塊）、**長條圖**（資料夾裡每個項目一條長條，由大到小，附大小與比例）、**放射圖**（目前資料夾在中心，每深一層就是外面一圈）和**樹狀圖**（可展開的資料夾分支，每張卡片附大小與比例）。按一下可以在資料夾樹中找到它，按兩下可以聚焦資料夾，四種圖會一起跟著。
- **最大的檔案**：整個掃描範圍內最大的 1,000 個檔案，附篩選框。
- **搜尋**（Ctrl+F）：依名稱，或 `*.mp4` 這類樣式，在整個掃描範圍內找檔案和資料夾。
- **清理**：列出通常可以刪掉的東西——暫存檔、瀏覽器快取、當機傾印檔、套件快取、可以重新建置的編譯產物、下載資料夾裡的舊安裝檔、空資料夾——依種類分組，並說明刪掉各種東西的影響。
- **重複檔案**（在「清理」裡）：把內容相同的檔案分組，並顯示多餘的副本佔了多少空間；明確選擇保留副本後，即可選取多餘的副本並移到資源回收筒。
- **與先前的掃描比較**：把掃描存成 JSON，之後就能看出哪些資料夾變大、變小、新增或消失。
- **檔案類型**與**檔案新舊**：依副檔名與種類（圖片、影片、壓縮檔…），以及依最後修改時間統計佔用的空間；按兩下一列就列出它最大的檔案。
- **安全地釋出空間**：「移到資源回收筒」每次都會先詢問，不會永久刪除；移動前會在背景核對項目，之後重新掃描受影響的資料夾。
- **匯出**資料夾清單或最大的檔案成 CSV（可用 Excel 開啟），或把資料夾樹匯出成 JSON。
- **English、繁體中文、简体中文**，隨時切換；內建「使用說明」。
- 連結與目錄連接會列出來，但不會跟進去計算，所以不會重複計算，連結形成的迴圈也不會讓掃描停不下來。無法讀取的資料夾列在「無法讀取」分頁，不會中斷掃描。

## 安裝

FileTree 可在 Windows、macOS 與 Linux 上執行。

**Windows，不需要 Python**：從 [Releases](https://github.com/JeffreyChen-s-Utils/FileTree/releases) 頁面下載 `FileTree-<版本>.exe` 直接執行，不必安裝。

從下一次發版起，同一頁也會提供 `FileTree-<版本>-windows-standalone.zip`。解壓縮**整個資料夾**後執行其中的 `FileTree.exe`，啟動較快；DLL、外掛及翻譯檔都要保留在旁邊。單檔 EXE 較方便攜帶，但每次啟動都會先解壓縮內含檔案。兩種形式都不需要 Python。

**有 Python 3.10 以上**，從 PyPI 安裝：

```bash
pip install je_file_tree
je-file-tree
```

或從原始碼執行：

```bash
git clone https://github.com/JeffreyChen-s-Utils/FileTree.git
cd FileTree
pip install -r requirements.txt
python start_file_tree.py
```

`python -m je_file_tree` 的效果相同。

### 編譯成獨立程式

要把 FileTree 給沒有安裝 Python 的人使用，可以用 Nuitka 編譯成程式資料夾或單一 `.exe`：指令與每個選項的用途請見 [nuitka.zh-TW.md](../nuitka.zh-TW.md)。

## 使用方式

1. **選擇要掃描的地方**：在起始頁按「選擇資料夾…」或其中一顆磁碟、把資料夾拖曳到視窗上，或在上方的方框輸入路徑後按 Enter。也可以從命令列直接開始掃描：`je-file-tree D:\Projects`（或 `python start_file_tree.py D:\Projects`）。
2. **邊掃邊看**：資料夾樹會立刻出現，FileTree 一邊加總，最大的資料夾一邊往上排；最大的檔案與檔案類型在掃描結束時補上。隨時可以按「停止」（或 Esc）結束掃描，已經讀到的部分會留下來並標示為不完整。
3. **找出佔空間的東西**：最大的資料夾排在最上面。按資料夾旁的箭頭看裡面的內容，或在右邊的圖表裡瀏覽。

### 看懂結果

| 位置 | 告訴你什麼 |
|---|---|
| 資料夾樹 | 大小、「磁碟大小」（實際佔用的空間：以整個叢集計算，通常比大小多一點；壓縮檔案較少，只存在雲端的檔案是 0）、「佔上層比例」（佔上一層資料夾的比例）、裡面的檔案數與資料夾數、最近一次變動的時間 |
| 圖表 | 「方塊圖」：每個檔案一個方塊，大小代表佔用的空間；每個資料夾頂端有名稱與大小。太小的檔案合併成灰色斜線方塊。「層數」決定顯示深度，「顏色」可依檔案類型或資料夾上色。「長條圖」：目前資料夾裡每個項目一條長條，附大小與比例。「放射圖」：目前資料夾在中心，每深一層就是外面一圈；按中心回上一層。「樹狀圖」：資料夾卡片附磁碟佔用大小與佔父資料夾的比例；按加號展開分支，按「其餘資料夾」載入更多，可切換左右或上下方向、按 Ctrl＋滾輪縮放並用捲軸移動。按兩下資料夾聚焦，按「上一層」回去；四種圖永遠顯示同一個資料夾，FileTree 會記住選取的圖表與樹狀圖方向 |
| 最大的檔案 | 最大的 1,000 個檔案；在篩選框輸入文字可以縮小清單，按兩下可以在資料夾樹中找到那個檔案 |
| 搜尋 | 名稱含有輸入文字的檔案和資料夾；樣式（`*.mp4`）要符合完整名稱，好幾個樣式用 `;` 分開（`*.iso;*.zip`）；搜尋框下方的條件可以縮小範圍，也可以單獨使用：大於或小於某個大小、最近一週／一個月／一年內改過或超過一、二、五年沒動、檔案類型、只有檔案或只有資料夾；搜尋可以取名儲存，之後再選回來；列出最大的 1,000 個符合項目，並顯示全部的數量和總大小 |
| 清理 → 建議 | 內建規則須符合檔齡與路徑／專案依據，提示會說明風險與重建方式。不確定群組須手動審查，預設不勾選；較低風險快取可整批送審，套件儲存庫不列入。「選項 → 清理政策」控制規則、檔齡及獨立的排除項目 |
| 清理 → 重複檔案 | 以開頭／完整雜湊找出相同大小的檔案（硬連結只算一份），預設最低 1 MB。每組明確選擇保留副本，核對路徑與估計，再選取已核對的多餘副本供 Delete。已變更、受保護、未驗證及硬連結群組保持原樣 |
| 檔案類型 | 每種副檔名佔用的空間；在表格上方選一種類型就只顯示那一類，按兩下一列會列出那種檔案裡最大的幾個 |
| 檔案新舊 | 依最後修改時間（一個月內……超過 2 年）統計佔用的空間；按兩下一列會列出那一段裡最大的檔案 |
| 無法讀取 | FileTree 沒有權限讀取的資料夾；裡面的內容不會算進去 |

### 釋出空間

在任何項目上按右鍵，可以開啟它、在檔案總管中顯示、複製路徑、在圖表中顯示、在 FileTree 以外改過東西之後重新掃描這個資料夾（其餘結果不變）、只掃描這個資料夾，或移到資源回收筒（macOS 與 Linux 是「垃圾桶」）。要一次移走好幾個項目，在資料夾樹、「最大的檔案」或「搜尋」清單裡用 Ctrl+按一下或 Shift+按一下選取，只會詢問一次，並列出它們和總大小。FileTree 移動任何東西之前都會先詢問，而且不會永久刪除。系統與程式的資料夾（Windows 資料夾、Program Files、AppData 裡的程式設定、使用者的個人資料夾，以及 macOS 與 Linux 上對應的位置）會說明原因並多問一次；暫存資料夾與快取不會，因為那正是要清理的東西。

移動每個項目前會核對掃描記錄的檔案身分、種類、大小、時間、目前上層路徑、解析後的保護狀態與資料夾內容。已變更、不存在或掃描不完整的項目會略過並說明原因；移動、略過與失敗分別計數。「停止」可取消剩餘項目；完成後會重新掃描受影響的上層資料夾。狀態列顯示移動容量，清空資源回收筒後才增加可用空間。記錄檔案身分會增加掃描時間與記憶體，Windows 尤其明顯。

移動失敗時，背景診斷會列出觀察到開啟檔案的程式及 PID（Windows Restart Manager 或 Linux `/proc`），不會自動關閉程式。資料夾診斷最多查詢 256 個已掃描檔案；無法存取的行程、資料夾控制代碼及其他失敗原因可能未知，觀察到占用程式也不能證明它就是失敗原因。

按「選取這一組」或「全部選取」會在確認移動前開啟審查佇列，逐項顯示路徑、規則、原因、日期、邏輯與配置大小、保護狀態及移除後果；表格下方會顯示選取項目的完整說明。可以取消勾選以保留項目，或開啟所在資料夾。上層與子項重複選取時只保留最外層。背景估計會把硬連結的共用配置空間只算一次，仍有其他名稱的檔案不列為可回收資料。清空資源回收筒後可回收的檔案資料以保守範圍呈現，共用區塊及資料夾中繼資料仍未知。

「**檔案 → 最近操作**」顯示最近 500 個已確認的操作，包含移動、略過與失敗。日誌只記錄時間、原始路徑、磁碟／檔案身分、理由、結果，以及 Qt 提供的資源回收筒位置，從不儲存檔案內容。僅追加的 JSONL 區段以原子方式寫入應用程式本機資料目錄的 `journal/`，保留 90 天／50 MB。先記錄確認才執行操作；無法記錄時略過移動。結果寫入失敗時會盡可能停止剩餘移動，並提示紀錄可能不完整。中斷後只有確認紀錄的操作，其最終結果未知。CSV 匯出會將家目錄前綴替換成 `{HOME}`；記錄資源回收筒位置不保證可還原。保留管理只移除 FileTree 自有的日誌區段，不會移除掃描的檔案。

規則會說明分類、依據、最低檔齡、風險與重建方式。近期或無日期項目不列入，資料夾依最新的子項計算（快取／建置／暫存／空資料夾 7 天、套件下載／當機傾印 30 天、安裝檔 90 天）。瀏覽器個人設定、套件儲存庫（`.m2/repository`、`.nuget/packages`、`.gradle/caches`）及僅名稱像快取／建置的資料夾不列入。專案輸出須有專案描述檔，Python 快取須有產生檔案的依據。暫存、當機證據、下載、建置輸出及空資料夾使用「手動審查」，預設不勾選且不包含在「全部選取」中。較低風險的快取仍須審查與確認。

「**選項 → 清理政策**」可啟用／停用每條規則、設定最低檔齡，或排除絕對路徑／名稱樣式（每行一個）。排除子項也會避免把其上層資料夾整個列入。這與「掃描時略過」獨立：不提出清理建議的資料仍計入磁碟用量。未修改時保留內建規則。儲存前會依目前掃描預覽增加／移除的候選數量與邏輯容量，修改設定會使預覽失效。政策儲存在 QSettings，僅接受經驗證的第 1 版 JSON 匯入（支援的規則、布林開關、0–36500 天與排除項目）。已儲存的設定無效時會停用建議，直到重新審查；手動審查風險不能調低，也不支援自行執行的規則。

### 看看哪裡變大了

用「**檔案 → 匯出 → 資料夾樹（JSON）**」把掃描存起來。之後重新掃描，選「**檔案 → 與先前儲存的掃描比較…**」開啟那個檔案，就會出現「**變化**」分頁，列出每個有變化的資料夾之前和現在的大小，變大最多的排在最前面；新的資料夾標示「新增」，消失的標示「已不存在」。在按「結束比較」之前，之後的重新掃描都會繼續比較。資料夾是依它在掃描資料夾底下的路徑對應，所以也可以拿來跟放在別處的同一份資料（例如備份）比較。

### 小知識

- 大小是檔案的實際大小，以二進位單位計算（1 KB = 1,024 位元組），和 Windows 檔案總管相同；可以在「檢視 → 大小單位」改用固定的單位。
- 在 Windows 上，FileTree 啟動時會像 TreeSize 一樣要求系統管理員權限，受保護的資料夾也能讀取。拒絕的話它照常以一般權限執行，讀不到的資料夾列在「無法讀取」分頁，那裡有「以系統管理員身分重新啟動」按鈕（「檔案」選單裡也有）。不想每次被問，可以關掉「檢視 → 啟動時要求系統管理員權限」。
- 「最大的檔案」、「檔案類型」與「檔案新舊」預設統計整個掃描範圍；按這幾個分頁右上角的「只看選取的資料夾」，就會改為跟著資料夾樹中選取的資料夾。
- 預設會計算隱藏檔案；關掉「檢視 → 包含隱藏檔案」，下次掃描就不會算進去。
- 清理建議會顯示已知容量，以及略過、無法讀取、尚未掃描的資料夾數；省略部分的容量為未知。不完整的分支不會被整個建議清理，也不會被視為空資料夾。掃描不完整時停用「全部選取」；清理前請重新掃描相關分支。更新時會清掉過期建議。
- 要讓某些資料夾每次都不掃描，把它們加進「檢視 → 掃描時略過」：像 `node_modules` 或 `*.cache` 這樣的名稱會略過所有同名的資料夾，路徑只略過那一個資料夾。略過的資料夾會以灰字列出，大小為 0。
- 語言、大小單位、視窗配置與最近掃描過的資料夾都會記住（Windows 上存在登錄檔的 `HKEY_CURRENT_USER\Software\JE-Chen\FileTree`）。

重複檔案的總量標為「邏輯大小」。每組請選取檔案列並按「保留選取的副本」，清單會標示保留副本的完整路徑，並保留名稱、日期與上層資料夾供比較。估計依這些選擇顯示不重複配置空間及清空資源回收筒後可回收資料的保守範圍，未決定的群組保持未知。「選取多餘的副本」只包含範圍、保護狀態、變更與硬連結名稱（含掃描範圍外的名稱）核對成功的群組。確認後會重新完整雜湊並核對該組所有檔案；核對失敗時整組保持原樣並要求重新掃描。「停止」取消剩餘工作。系統移動失敗仍可能造成部分批次完成；資源回收筒移動不是整組原子操作。壓縮／稀疏檔案依配置大小計算，雜湊不開啟已知的雲端佔位檔。共用區塊及資料夾中繼資料仍未知，移到資源回收筒本身不釋放空間。隔離磁碟實測仍待完成。

相同資料夾會列在檔案群組上方，以「副本 = 原始資料夾」顯示，沿用搜尋所得的雜湊，不會再讀取內容。每個非空檔案都須有已驗證雜湊，且相對名稱、大小、雜湊與空資料夾結構須相同。未雜湊的小檔案／獨有檔案、連結及不完整分支會阻止資料夾配對。已包含在上層配對中的子項不重複列出，其他位置的額外副本仍會列出。這些列僅比對搜尋快照，不代表可移除資料夾。

### 容量明細

資料夾樹上方會顯示系統已用／可用空間，以及硬連結只算一次的檔案配置估計。「容量明細」會區分依名稱計算的配置、硬連結重複量、已讀取的資源回收筒資料（已包含）、略過／無法讀取的範圍及其他掛載磁碟。完整掃描整個磁碟時，會把無法解釋的差額列為「未能歸帳」。僅掃描資料夾、掃描不完整、缺少識別資訊或配置估計超過系統已用空間時，都無法核對整個磁碟。檔案系統中繼資料／保留空間、略過的位元組及其他磁碟的總量保持「未知」，而非 0。系統容量與檔案快照不是同時量測，共用區塊、快照與 Windows 配置估計會影響差額；仍待 NTFS／ext4／APFS 測試磁碟驗證，因此帳本只稱為估計。命令列的掃描記錄也會在 `capacity` 欄位包含這些數字。跨磁碟的資料夾掛載點只列出、不繼續掃描；POSIX 同磁碟 bind mount 的偵測仍待實作。

在資料夾樹的欄位標題按右鍵，可選擇顯示的欄位，設定會保留。名稱欄保持顯示並預設為可讀寬度，額外欄位可水平捲動。「**占磁碟比例**」可選擇顯示，與「占上層比例」並列，依邏輯位元組除以系統回報的磁碟總容量。容量尚未取得、資料夾樹變更後及其他磁碟項目會顯示未知；硬連結名稱仍分別計算，因此不是配置或可回收空間。

## 不開視窗的命令列

命令列入口只使用核心，不會載入 Qt。CSV／JSON 匯出與視窗相同，以原子方式寫入；比較會列出絕對變化最大的項目，最多 `--limit` 筆（預設 1,000）。標準輸出是逐行 JSON，使用固定欄位（`file-tree-cli/1`）並包含掃描涵蓋範圍；比較會增加 `changes` 記錄。錯誤以 JSON 寫到 stderr。預設兩個工作執行緒，可用 `--workers`、可重複的 `--exclude` 樣式及 `--no-hidden` 控制掃描。

```bash
je-file-tree-cli scan D:\ --folders folders.csv --largest largest.csv --json tree.json
je-file-tree-cli scan D:\ --compare old.json --limit 20
python -m je_file_tree.cli scan D:\ --exclude node_modules --workers 2
```

結束代碼：**0** 涵蓋範圍完整、**1** 不完整（包含排除及無法讀取的項目）、**2** 參數錯誤、**3** 掃描／比較／匯出 I/O 錯誤或儲存的掃描格式無效、**130** 已中斷。Ctrl+C 會停止掃描並匯出已讀取的部分；再次按 Ctrl+C 則立即中止。每份匯出獨立完成原子寫入，後續匯出失敗不會撤銷先前完成的報告。命令列不提供移除或自動清理。

## 開發

Python 整合請參閱[核心 API 指南](../docs/core-api.md)：公開匯入路徑、掃描／搜尋／重複檔案／比對範例、取消、原子匯出及配置空間限制。核心不會匯入 Qt。

```bash
pip install -r dev_requirements.txt
python -m pytest
python -m ruff check .
python tools/make_screenshots.py
```

`tools/make_screenshots.py` 會用一個虛構的資料夾重新繪製 README 裡每種語言的圖片。程式架構、主要流程與設計規則寫在 [architecture.md](../architecture.md)。

整碟掃描可以設定資源預算後量測（預設兩個工作執行緒、512 MB、180 秒）。因預算而停止的掃描會在報告標為不完整；重複檔案雜湊另有時間限制。CSV 與 JSON 匯出以串流寫入暫存檔，再取代目的檔案，大型掃描也不必在記憶體保留另一份匯出資料。

```bash
python tools/measure_scale.py C:\ --gui --memory-mb 768 --duplicates-seconds 10 --output scale.json
```
