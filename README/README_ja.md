# FileTree

**ディスクの容量を何が使っているのか、すぐに確認。**

FileTree はフォルダーやドライブをスキャンし、容量の大きいファイルやフォルダーを表示します。
フォルダーツリー、色付きの図、大きいファイルの一覧を見ながら、残すものや整理するものを選べます。

[English](../README.md) | [繁體中文](README_zh-TW.md) | [简体中文](README_zh-CN.md) | [日本語](README_ja.md) | [한국어](README_ko.md)

![FileTree：左にフォルダーのサイズ、右に容量の分布を表示](../docs/images/main_window_ja.png)

## できること

- **大きいファイルやフォルダーを探す**：大きい順に確認し、図で容量の割合を把握できます。
- **検索・絞り込み**：名前、種類、サイズ、更新日時でファイルを探せます。
- **整理候補を確認する**：キャッシュ、一時ファイル、重複ファイルを調べてから操作できます。
- **増えたフォルダーを見つける**：以前のスキャンと比較し、容量が増えた場所を確認できます。
- **レポートを保存する**：結果を CSV、JSON、Excel に出力できます。
- **言語を切り替える**：英語、繁体字中国語、簡体字中国語、日本語、韓国語に対応しています。

## インストール

### Windows：Python は不要

1. [Releases](https://github.com/JeffreyChen-s-Utils/FileTree/releases) から `FileTree-<version>-windows-standalone.zip` をダウンロードします。
2. ZIP を**すべて展開**します。
3. 展開したフォルダーの `FileTree.exe` を実行します。他のファイルも同じ場所に残してください。

Windows でインストールできる MSI インストーラーも用意されています。

### Windows・macOS・Linux：Python を使う

**Python 3.10 以降**が必要です。

```bash
python -m pip install je_file_tree
je-file-tree
```

Windows では `python` の代わりに `py -3` を使えます。
ソースからの実行や単独で動くアプリの作成は、[詳細ガイド](../docs/guide_ja.md)と[ビルドガイド](../nuitka.ja.md)を参照してください。

## 使い始める

1. **フォルダーやドライブを選ぶ**。フォルダーをウィンドウにドラッグしても開始できます。
2. **スキャンが終わったら確認する**。大きいフォルダーやファイルから見ていきます。図の四角が大きいほど、多くの容量を使っています。
3. **不要な項目を確認する**。右クリック → **ごみ箱に移動**を選びます。実行前に確認画面が表示されます。

スキャンはいつでも停止できます。読み取り済みの結果は残り、不完全な結果として表示されます。

## 知っておきたいこと

- ごみ箱に移しただけでは空き容量は増えません。**ごみ箱を空にすると容量が解放されます**。
- 整理候補は自分で確認してください。バックグラウンド監視は初期設定では無効で、自動整理も行いません。
- 読み取れないフォルダーは**問題点**に表示され、その中身は合計サイズに含まれません。
- スキャンはシンボリックリンクやジャンクションをたどりません。ファイルサイズとディスク使用量は異なることがあります。
- Windows では起動時に管理者権限を求めることがあります。拒否しても、読み取り権限のあるフォルダーをスキャンできます。
- ごみ箱を空にする操作や重複ファイルのハードリンク化には、それぞれ確認と注意点があります。先に[詳細ガイド](../docs/guide_ja.md)をお読みください。

## よく使うショートカット

| キー | 操作 |
|---|---|
| Ctrl+O | フォルダーを選ぶ |
| F5 | 再スキャン |
| Esc | スキャンを停止 |
| Ctrl+F | 検索 |
| Delete | 選択項目をごみ箱へ移動 |
| F1 | ヘルプを開く |
| Ctrl+Q | 終了 |

macOS では Ctrl の代わりに ⌘ を使います。再スキャンは ⌘R です。
